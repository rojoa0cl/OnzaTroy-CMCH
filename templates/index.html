Guía y Tutorial de Uso

1. Procesamiento de Imágenes

Las impresoras de producción e imprentas profesionales requieren archivos TIFF sin compresión (raw) para evitar pérdidas y fallos de RIP. Esta herramienta asegura:

  • Conversión garantizada a espacio de color RGB.
  • Compresión en modo None (sin pérdida).
  • Extensión estrictamente formateada como .tiff (doble 'f') para compatibilidad total.

2. Códigos para ScanTrust

Requiere el archivo code.csv. Mapea la columna extended_id y le asocia el folio correlativo consecutivo en la columna serial_number. El archivo resultante se delimita por punto y coma (;).

3. Códigos para Ricoh

Requiere el archivo files.csv. Extrae el nombre del archivo de la columna image_file, sustituye la extensión por .tiff y lo asocia al folio. Salida delimitada por punto y coma (;).

4. Códigos para Control de Calidad (CC)

Requiere el archivo code.csv. Asocia extended_id, folio correlativo y la URL completa full_url. Salida delimitada por comas (,).
